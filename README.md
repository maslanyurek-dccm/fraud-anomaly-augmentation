# Reassessing Unsupervised Anomaly Augmentation for Fraud Detection

Code, raw results and figures for the article:

> M. Aslanyürek, *Reassessing Unsupervised Anomaly Augmentation for Fraud Detection: The Roles of Distribution Shift, Learner Instability, and Run-to-Run Variability* (under review).

This repository contains the code, raw results and figures for the article. It lets readers (i) inspect every run behind the reported numbers, (ii) regenerate all figures from those runs, and (iii) re-run the experiments from scratch.

## Repository structure

```
experiments/
  experiment_16_variance_controls.py   CreditCard: learners x pipelines x regimes x configs, 20 replicates
  experiment_17_crossfit_psi.py        CreditCard: in-sample vs. cross-fitted PSI of anomaly features
  experiment_18_baf_variance_controls.py  BAF: multi-seed, controls, two learners, 10 replicates
  legacy/                              earlier exploratory scripts (see legacy/README.md)
results/                               raw per-run results used in the article (CSV + settings.json)
figures/                               Figures 1-6 (PNG 300 dpi + editable SVG), regenerated by scripts/make_figures.py
scripts/
  make_figures.py                      regenerates figures/ from results/
  run_all.sh | run_all.bat             re-runs experiments 16-18 into results_repro/
data/                                  place the datasets here (not included; see data/README.md)
```

## Experiments

| Folder in `results/` | Script | Content |
|---|---|---|
| `experiment_16` | `experiment_16_variance_controls.py` | CreditCard: LightGBM and XGBoost, unscaled and scaled pipelines, original / bagging / regularised regimes, anomaly features and uninformative controls, 20 replicates |
| `experiment_16_reg` | `experiment_16_variance_controls.py --learners lgbm --regimes reg` | CreditCard: corrected regularised LightGBM regime |
| `experiment_16_mech` | `experiment_16_variance_controls.py` with `bag_hess`, `bag_mds`, `bag_l2` regimes | CreditCard: LightGBM leaf-value constraints |
| `experiment_17` | `experiment_17_crossfit_psi.py` | CreditCard: in-sample vs. cross-fitted PSI of anomaly features |
| `experiment_18` | `experiment_18_baf_variance_controls.py` | BAF: two learners, two pipelines, original / bagging regimes, anomaly features and controls, 10 replicates, Base and Variant I-V Month 7 |

Note: the 286 LightGBM runs with `Regime == "reg"` in `results/experiment_16/runs.csv` used a misconfigured early-stopping rule and are **excluded** from the analysis; the corrected runs are in `results/experiment_16_reg`.

## Result files

Each `runs.csv` has one row per trained model (experiment 18: one row per model and evaluation set). Main columns:

| Column | Meaning |
|---|---|
| `Learner`, `Pipeline`, `Regime`, `Config`, `Replicate` | experimental cell (`raw`/`enc` = unscaled, `scaled` = StandardScaler) |
| `Test_AUPRC` / `AUPRC`, `Test_ROC_AUC` / `ROC_AUC` | threshold-free test metrics |
| `Val_AUPRC` | validation AUPRC |
| `Recall_at_*FPR`, `TP_at_*`, `FP_at_*`, `Precision_at_*` | operating-point metrics (thresholds set on validation negatives) |
| `Log10_ValNeg_q95` | log10 of the 5% FPR threshold (probability-saturation diagnostic) |
| `Added_SHAP_Rank`, `Added_Gain_Rank` | rank of the added column among all features |
| `IF_Seeds` | Isolation Forest seeds of the replicate (`100r+1 … 100r+5`) |

`summary.csv` aggregates runs per cell; `settings.json` records arguments and package versions; `experiment_18/paired.csv` holds paired differences vs. M0 with Wilcoxon p-values.

## Reproducing

```bash
pip install -r requirements.txt
# put the datasets into data/ (see data/README.md), then from the repository root:
bash scripts/run_all.sh          # Windows: scripts\run_all.bat
python scripts/make_figures.py   # regenerates figures/ from results/
```

Approximate run times on a recent laptop: experiment 16 about 1-2 h, experiment 16_reg about 20 min, experiment 16_mech about 15 min, experiment 17 a few minutes, experiment 18 about 2-3 h. All scripts are resumable: re-running the same command skips completed runs. Use `--quick` for a short smoke test. Do not run two scripts into the same output folder at the same time.

Results were produced with Python 3.14, LightGBM 4.7.0, XGBoost 3.2.0, scikit-learn 1.8.0, NumPy 2.4.3 and pandas 3.0.1 on Windows 11. Other versions or platforms may give slightly different numbers, particularly for LightGBM.
