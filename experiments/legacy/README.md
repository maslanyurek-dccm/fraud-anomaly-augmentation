# Legacy experiments

These are the earlier exploratory scripts (experiments 00–15), kept for
transparency. The controlled experiments are in the parent folder
(experiments 16–18).

Notes:

- Experiments 12 and 14 train LightGBM on unscaled features, whereas
  experiment 15 uses scaled features.
- Experiment numbers 09–11 and 13 were not retained.

Scripts expect the data files in the working directory. Extra packages:
`pip install -r ../../requirements-legacy.txt`.
